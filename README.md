# 스파이를 찾아라! v22

## v22 변경
- 맵을 운동장 + 1층 두 공간만 사용
- 2층 / 3층 및 계단 이동 제거
- 운동장 ↔ 1층은 왼쪽 / 가운데 / 오른쪽 3개 출입구로 이동
- 남은 시간이 1분이 되면 살아 있는 모든 스파이 정체 자동 공개
- `이제 스파이들의 정체가 드러났어요!` 짧은 팝업 + 경고음
- 경찰 오인 공격 시 하트가 즉시 감소하도록 전용 실시간 이벤트 추가
- 클라이언트도 wrongHit 수신 즉시 HUD 갱신
- 경찰 막대기를 경찰봉 스타일로 변경
- 경찰 공격 판정: 바라보는 방향 기준 앞쪽 180도(±90도) 반원
- 기존 QR, 재접속, 누적점수, 교사채팅, 강제종료, 승리 빵빠레 기능 유지
