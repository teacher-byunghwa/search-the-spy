# 스파이를 찾아라! v11

GitHub + Render 무료 Web Service 배포용 실시간 멀티플레이 버전입니다.

## v11 주요 변경
- 자동 학생 이동속도 상향: 실제 플레이어와 훨씬 비슷한 속도
- 실제로 2~5초 멈춰 있는 학생, 대화하는 학생, 무리 이동, 달리기, 점프 유지
- 계단 이동 판정 및 그래픽을 더 작게 축소
- 1층 정문 ↔ 운동장 이동 추가
- 운동장: 트랙, 축구장, 농구장, 나무, 벤치, 학교 외관
- 학교 그래픽 입체감 및 교실/복도 표현 강화
- 태블릿/폰 가상 조이스틱을 CSS/JS 양쪽에서 강제 표시
- 캐릭터 눈을 흰자+동공으로 선명하게 표현
- 이동하면서 점프 가능
- 닉네임 입력 후 남자/여자 캐릭터 선택
- 게임 시작 전 전원 5초 카운트다운 팝업
- 화면/역할/층/게임 시작/종료에 WebAudio 효과음
- 대기실 QR을 크게 표시
- 교사 관전 중 `QR 다시 보기` 버튼으로 큰 QR 팝업 재표시
- 같은 기기에서 화면 꺼짐/새로고침/네트워크 전환 후 재접속 복구
- 게임 종료 후 같은 방에서 바로 새 게임 시작
- **누적 점수:** 승리한 팀의 모든 플레이어에게 +1점
- 새 게임을 시작해도 같은 방이면 점수 유지, 새 방 생성 시에만 초기화
- 교사 화면과 종료 화면에 누적 점수판 표시

## 점수 규칙
- 경찰팀 승리 → 해당 라운드 경찰 전원 +1점
- 스파이팀 승리 → 해당 라운드 스파이 전원 +1점
- 라운드 중 탈락/유령 여부와 관계없이 그 라운드의 승리팀이면 +1점
- 같은 방에서 `새 게임 시작` 시 누적
- 새 방을 만들면 0점부터 다시 시작

## 조작
PC:
- 이동: WASD / 방향키
- 경찰 공격: Space
- 점프: F
- 층 이동: 계단 구역으로 직접 이동
- 운동장: 1층 정문으로 직접 이동

태블릿/휴대폰:
- 왼쪽 가상 조이스틱 이동
- 오른쪽 공격/점프 버튼
- 스파이 후반 부스터 버튼
- 이동 중 점프 버튼을 동시에 눌러 이동 점프 가능

## Render
Build Command: `npm install`
