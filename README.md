# 스파이를 찾아라! v9 — QR 참가 + 재접속 복구

GitHub + Render 배포용 Node.js / Socket.IO 실시간 멀티플레이 버전입니다.

## v9 변경사항

- 학생 화면에서 `NPC`라는 표현을 제거하고 모두 `학생`으로 표시합니다.
- 교사 설정 화면에서 학생 수 산식(`스파이 수 × 7`)을 노출하지 않습니다.
- 교사가 방을 만들면 대기실에 **학생 참가 QR 코드**가 자동 생성됩니다.
- 학생이 QR 코드를 찍으면 해당 Render 주소가 열리고 방 코드가 자동 입력된 **학생 참가 화면**으로 이동합니다.
- 참가 링크 복사 버튼도 제공합니다.
- 학생 참가 정보는 기기의 `localStorage`에 저장됩니다.
- 태블릿/폰 화면 잠금, 일시적인 Wi‑Fi 끊김, 브라우저 새로고침 등으로 Socket.IO 연결이 끊어져도 같은 기기로 돌아오면 기존 참가자 ID와 역할을 다시 연결합니다.
- 게임이 이미 시작된 뒤 재접속하면 대기실부터 다시 시작하지 않고 기존 역할/위치/생명 상태를 받아 게임으로 복귀합니다.

## 중요
재접속 복구는 **같은 Render 서버 프로세스에 방이 살아 있는 동안** 동작합니다. Render 무료 인스턴스 자체가 재시작되면 현재 게임 방은 메모리에서 사라질 수 있습니다. 실제 수업 중 다른 참가자들이 계속 접속해 실시간 메시지가 오가는 상황에서는 일반적인 화면 잠금/재접속에 대응하도록 설계했습니다.

## 기존 게임 기능
- 교사 방 생성, 학생 동시 접속
- 스파이 1~15명, 게임시간 1~20분
- 자동 학생 캐릭터 수는 내부적으로 스파이 수에 맞춰 생성
- 3층 학교와 실제 계단 구역 이동
- 학생 캐릭터와 위장 스파이 외형 동일
- 학생 AI: 걷기, 멈춤, 대화, 무리 이동, 달리기, 점프, 계단 이동
- 플레이어 점프 / 말풍선
- 경찰 몽둥이 공격, 오인 3회 탈락
- 스파이 검거 시 경찰 생명 3칸 완전 회복
- 후반 스파이 10초 부스터
- 탈락 후 유령 이동
- 교사 전체 관전 화면
