# 스파이를 찾아라! v8 — NPC 상호작용 + 플레이어 말풍선

## v8 추가 기능

### NPC끼리 실제 상호작용
NPC들이 이제 서로 독립적으로 랜덤 이동만 하지 않습니다.

- 가까운 NPC 둘이 서로 마주친 상황에서 잠시 멈춰 대화
- 한 NPC가 `"오늘 급식 뭐지?"`라고 하면 다른 NPC가 `"그러게!"`, `"ㅋㅋㅋ"`, `"같이 가자!"`처럼 반응
- 2~3명 규모의 작은 무리가 만들어져 한 명을 따라 같이 이동
- 무리가 함께 복도를 이동하다가 다시 흩어짐
- 기존 걷기 / 멈춤 / 달리기 / 점프 / 계단 이동과 섞여 작동

### 모든 플레이어 말풍선
경찰과 스파이 모두 말풍선을 사용할 수 있습니다.

화면의 `💬 말하기` 버튼을 누르면:
- 같이 가자~
- 쉬는 시간이다!
- 오늘 급식 뭐지?
- ㅋㅋㅋ
- 직접 입력(최대 24자)

를 사용할 수 있습니다.

- 말풍선은 약 3초간 캐릭터 위에 표시됩니다.
- 과도한 도배 방지를 위해 서버에서 약 1.8초 쿨다운을 적용합니다.
- 스파이가 NPC와 같은 말투를 사용해 위장하는 것도 가능합니다.

## 계단
계단 버튼은 없습니다.
캐릭터가 실제 `▲ 위층으로` / `▼ 아래층으로` 구역까지 걸어가면 자동으로 층이 바뀝니다.

## 기존 기능
- GitHub + Render + Socket.IO 실시간 멀티플레이
- 교사 방 생성 / 학생 방 코드 참가
- 스파이 1~15명
- NPC = 스파이 수 × 7
- NPC/스파이 외형 동일
- 랜덤 학생 외형
- 3층 학교
- 플레이어/NPC 점프
- 경찰 몽둥이 공격
- 오인 공격 3회 탈락
- 스파이 검거 시 경찰 생명 ❤️❤️❤️ 회복
- 스파이 후반 10초 부스터
- 유령 이동
- 교사 관전 화면
