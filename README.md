# 스파이를 찾아라! v27

## v27 변경
- NPC 수: 스파이 수 × 2.5 (반올림)
- 운동장 왼쪽 출입구 주변 놀이터/구조물 이동, 3개 출입구 앞 넓은 안전 통로 확보
- 기존 수동/자동 스파이 부스터 버튼 제거
- 남은 시간 1분 30초에 스파이 정체 공개와 동시에 붕어빵 등장
- 운동장 8개 + 1층 8개, 총 16개
- 붕어빵은 20초 동안만 유지
- 살아 있는 스파이는 붕어빵 1개를 먹으면 10초 동안 1.8배 속도 부스터
- 스파이 1명당 한 번만 붕어빵 부스터 획득 가능
- 교사 관전 화면에서도 붕어빵 표시
- 기존 v26 기능 유지
