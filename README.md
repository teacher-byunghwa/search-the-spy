# 스파이를 찾아라! v30

## v30 변경
- 태블릿에서 조이스틱을 누른 상태로 점프 버튼을 동시에 눌러도 정상 작동하도록 멀티터치 입력 구조 재작성
- 태블릿 터치는 Pointer Capture 대신 터치 identifier 기반으로 조이스틱을 독립 추적
- 점프 / 공격 / 부스터 버튼도 별도 touchstart 입력으로 처리
- 게임 화면에서 두 손가락을 사용해도 브라우저 화면 확대/축소가 발생하지 않도록 차단
- Safari gesturestart / gesturechange / gestureend 확대 제스처 차단
- 전체맵 탭에서는 기존 핀치 확대/축소 기능을 그대로 유지
- 붕어빵은 스파이와 경찰 모두 획득 가능
- 붕어빵을 먹는 즉시 빨라지지 않고 `부스터 ×N` 횟수로 저장
- 먹은 개수만큼 부스터 횟수가 누적됨
- 부스터 버튼을 눌렀을 때 1회 소비하여 10초 동안 1.8배 속도
- 이미 부스터 사용 중이면 추가 횟수를 실수로 소비하지 않음
- 기존 v29 안정화 기능 유지
