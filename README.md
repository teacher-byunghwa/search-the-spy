# 스파이를 찾아라! v31

## v31 변경
- 경찰봉을 경찰 본인뿐 아니라 스파이/다른 경찰/교사 화면에서도 항상 표시
- 경찰봉 방향은 해당 경찰이 바라보는 방향과 일치
- 내 경찰이 공격할 때는 기존 휘두름 애니메이션 유지
- 기존 자기 화면 전용 경찰봉을 제거해 이중으로 보이지 않게 처리
- 운동장 나무를 입체적인 수관/줄기/그림자 형태로 개선
- 나무 그림 좌표와 실제 충돌 판정을 완전히 동일하게 통일
- 캐릭터와 NPC가 나무를 통과하거나 밟을 수 없도록 원형 장애물 충돌 추가
- 나무 충돌은 점프로도 통과할 수 없으며 나무 둘레로 돌아가야 함
- 서버와 학생 태블릿 모두 동일한 나무 충돌 데이터 사용
- 기존 v30 멀티터치 및 붕어빵 저장형 부스터 기능 유지
