# 스파이를 찾아라! v36

## v36 변경

### 라운드 MVP
- 기존 팀 승리 점수와 별개로 종료 화면에 MVP 표시
- 경찰 승리 시: 가장 많은 스파이를 맞힌 경찰
- 스파이 승리 시: 가장 오래 살아남은 스파이
- 승패와 별개로: 붕어빵을 가장 많이 먹은 학생
- 동률이면 공동 MVP로 여러 이름 표시

### 교사 이벤트 버튼
- 교사 화면에 `전체 속도 UP` 이벤트 추가
- 교사가 1~60초 사이 시간을 초 단위로 직접 설정
- 발동 시 모든 플레이어 이동 속도가 35% 증가
- 교사 화면에 `전체 위치 5초 공개` 버튼 추가
- 발동 후 5초 동안 모든 학생 닉네임이 모든 학생 화면에서 표시
- 기존 v35 기능 유지
