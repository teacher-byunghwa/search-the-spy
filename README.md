# 스파이를 찾아라! v12

## 주요 변경
- 학생 참가 후 대기화면 대신 실제 1층 맵에서 자유 이동하며 다른 참가 학생을 실시간으로 볼 수 있음
- 대기 중 점프/채팅 가능
- 교사 관전 맵 확대/축소(마우스 휠, +/−) 및 드래그 이동
- 모바일 멀티터치 수정: 조이스틱을 누른 채 다른 손가락으로 점프/공격 가능
- 교사 시작 → 같은 팀 전원 확인 10초 → `게임 시작!` 팝업 → 즉시 시작
- 스파이는 스파이 전원, 경찰은 경찰 전원을 확인
- 플레이어/스파이/NPC 기본 이동속도 모두 240으로 통일(부스터만 예외)
- NPC 네트워크 위치를 클라이언트에서 보간하여 끊김 완화
- NPC 서버 전송 주기 80ms로 개선
- 학교/운동장 2.5D 스타일 강화, 벽 충돌 적용
- 교실 벽을 통과할 수 없음
- 운동장 농구장 울타리는 점프 중에만 넘어갈 수 있음
- 운동장 크기 확장(3200×2000)
- 계단은 작은 판정 구역 + 클라이언트 즉시 전환으로 반응 개선
- 남은 시간/장소 표시 글씨 확대
- 채팅/상태 피드에 탈락자 표시
- 부스터 사용 중 캐릭터 옆에 ⚡/💨 효과 표시
- 교사 첫 화면/학생 닉네임 화면 현대적 디자인 + 귀여운 스파이 마스코트
- `만든이: 김병화`
- NPC 수 = 스파이 수 × 11
- NPC는 운동장/1층/2층/3층에 최대한 균등 분배
- 같은 방에서 승리팀 +1점 누적 유지

## 조작
PC: WASD/방향키, Space 공격, F 점프
모바일: 왼쪽 조이스틱 + 오른쪽 점프/공격(동시 입력 가능)

## Render
Build: `npm install`
Start: `npm start`
