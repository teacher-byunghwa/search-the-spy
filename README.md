# 스파이를 찾아라! v21

v20 기반 계단 판정 수정판입니다.

## v21 변경
- 계단 네모칸에 캐릭터가 어느 방향에서든 `닿기만 하면` 즉시 층 이동
- 위→아래 방향으로 지나가야만 작동하던 느낌 제거
- 왼쪽/오른쪽에서 접근해도 동일하게 작동
- 계단 그래픽의 실제 네모칸 좌표와 이동 판정 좌표를 일치
- 캐릭터 중심점이 아니라 캐릭터 몸의 반경까지 포함해 접촉 판정
- 새 층으로 이동한 뒤 계단 네모 밖 복도에 착지해 다시 오르내리는 오작동 방지
- 기존 v20의 빵빠레, 채팅, 점수, QR, 충돌, 3개 출입구 기능 유지
