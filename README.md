# 스파이를 찾아라! v32

## v32 변경
- 게임 시작 시 플레이어가 나무 위/나무 바로 옆에 생성되지 않도록 스폰 로직 수정
- 운동장 스폰은 나무/놀이터/울타리/건물벽에서 떨어진 안전 후보 좌표만 사용
- 1층 스폰도 교실 벽과 출구 벽에 끼이지 않는 복도 안전 좌표 사용
- NPC도 동일한 안전 스폰 로직 사용
- 여러 명이 한 곳에 몰리지 않도록 후보 좌표를 매번 섞어서 배정
- 후보 좌표가 모두 막힌 경우에도 최대 80회 안전 랜덤 탐색 후 배치
- 기존 v31의 나무 충돌, 경찰봉 표시, v30 멀티터치/붕어빵 부스터 기능 유지
