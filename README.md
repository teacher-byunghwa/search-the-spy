# 스파이를 찾아라! v23

## v23 변경
- 1층에 남아 있던 계단 그래픽 완전 제거
- 운동장과 1층의 과거/중복 출입구 그래픽 제거
- 운동장 ↔ 1층 출입구를 왼쪽 / 가운데 / 오른쪽 딱 3개로 통일
- 출입구 그래픽, 이동 판정, 운동장 건물 벽 충돌 좌표를 같은 좌표로 통일
- 학생 화면에 `🗺️ 전체맵` 버튼 추가
- 전체맵에서 운동장과 1층을 동시에 보고 현재 자신의 위치를 파란색 `나` 마커로 확인 가능
- 전체맵을 열어 둔 상태에서도 자신의 위치가 계속 갱신됨
- 대기실 참가 학생 스폰 위치를 교실/벽이 아닌 넓은 중앙 복도로 제한
- 입장 직후 모든 학생의 phase를 lobby로 확실히 적용하고 이동 루프를 즉시 활성화
- 게임 시작 전에도 키보드/태블릿 조이스틱/점프 이동 가능
- 기존 v22의 1분 스파이 공개, 경찰봉, 즉시 하트 감소, 채팅, 강제 종료, 빵빠레 유지
